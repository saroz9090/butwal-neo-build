# Butwal Construction & Builders (Dang Branch: Dang Construction & Builders)

Leading architectural design, 3D floor planning, municipal building permit assistance, and turnkey residential & commercial construction company serving Butwal (Rupandehi) and Dang Valley (Ghorahi, Tulsipur, Lamahi).

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, shadcn-ui, motion
- **Database & Auth**: Google Cloud Firebase Firestore & Firebase Auth
- **AI Integration**: Google GenAI SDK (Gemini 3.7 Flash)
- **Backend & Server**: Node.js Express server with Vite middleware mode

## Getting Started

```sh
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
